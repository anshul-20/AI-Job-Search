📦 30-Second Chrome Installation

  1. Open Google Chrome (or Brave / Microsoft Edge) and navigate to chrome://extensions
  2. Turn ON the Developer mode toggle in the top-right corner.
  3. Click the Load unpacked button in the top-left corner.
  4. Select the extension folder located at: d:\AI-Job-Search\extension
  5. Navigate to any job page on LinkedIn, Greenhouse, Lever, Workday, or Ashby — you will see the ⚡ 1-Click Apply widget ready to auto-fill!
